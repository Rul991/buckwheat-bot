## 2.0.0

- Тех. обновление:
  - Переход с `Telegraf` на `Grammy`
  - Изменен формат передачи данных внутри кнопок (JSON -> ProtoBuf + Base64)
  - Кнопки определяются в коде, а не в JSON файлах
  - Для текстов используется библиотека `@grully/i18n`
  - Добавлена ротация для логирования
  - Обновлена работа со скроллерами
  - Часто вызываемые переменные теперь доступны из `ctx.vars`
  - Все кнопки-списки кэшируются
  - Добавлена обработка миграции чатов
- Добавлены новые единицы времени (Месяцы, года)
- Добавлена поддержка смешанного времени (пример: 1д20,1ч30.5м12с)
- Обновлен список простых команд
- Теперь бот может обрабатывать форматирование
- Все настройки теперь находятся в одной команде
- Количество сообщений считаются за день, за месяц, за год и за все время
- Щиты теперь имеют прочность
- Рулетка облегчена: для приза нужен ряд из 8 побед вместо 10
- За идею можно переголосовать, если есть время
- Баквит теперь умеет рандомно отправлять стикер из стикерпака, настраивается с помощью `баквит стикер`
- Переработано управление РП-команд (большие команды -> кнопки + сообщения)
- Добавлено возможность получить класс `Финального босса` с помощью определенных действий
- Добавлены сокращения команды
- Изменен функционал `Шкатулки жадности`
- Добавлены новые команды: 
  - `баквит сокращения`
  - `баквит реакция`
  - `баквит стикер`
  - `баквит сообщения`
- Аватарки профиля теперь могут быть картинкой, гифкой или видео
- И прочие мелкие (и не очень) изменения
